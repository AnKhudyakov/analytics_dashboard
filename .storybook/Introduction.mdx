# Analytics dashboard UI kit

Shared components of the [analytics dashboard](https://github.com/AnKhudyakov/analytics_dashboard)
by Andrei Khudiakov.

The project follows Feature-Sliced Design; everything documented here lives in
the `shared/ui` segment and knows nothing about the domain. Domain components
live in `entities/*/ui` and are composed by widgets and pages.

Use the toolbar to switch between the light and dark theme — every component is
built on the same design tokens and must be readable in both.
